# My UPSC — Android APK wrapper

This project packages the selected `UPSC_CSE_Tracker_Professional_Edition (1)(1).html` as the app's local WebView screen.

## Build
1. Upload the contents of this project to a GitHub repository.
2. Open **Actions** and run the **Build Android APK** workflow.
3. Download the APK artifact from the completed workflow.

The app loads `app/src/main/assets/index.html` locally. This does not modify or replace your hosted website. Browser/WebView storage is device-local and is not automatically synced with Chrome or the website. Keep separate JSON exports before installing or changing app versions.
